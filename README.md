# Life Compass AI OS Personal Edition v3.8.0

Life Compass AI OSは、理想の未来、現在の現実、健康・医療、お金、家族、目標、最優先課題、期限、人生経験を一つの正本にまとめ、AIと一緒に「これからの人生の方向」を考えるための人生OSです。

## v3.8.0 の修正

「人生設計 → 夢・楽しみ」の3つの欄を、PC・スマホの両方で探しやすくしました。

- 欲しいもの：キーワード検索＋分野＋実現状況で絞り込み
- 行きたい場所：キーワード検索＋観光・旅行／旅館・ホテル／温泉・入浴／飲食店・カフェ／買い物／医療機関／イベント・体験施設／その他で絞り込み
- やってみたいこと：キーワード検索＋挑戦・成長／趣味・体験／人生で一度は＋実現状況で絞り込み
- 結果件数と「絞り込みを解除」を追加
- PCは3列表示を維持し、各列の中で即時検索
- スマホは従来の3タブ切替を維持し、カテゴリを横スクロールで選択

既存データ形式、Google Sheets正本、同期方式、GAS APIは変更していません。v3.8.0への更新ではGASの再デプロイは不要です。

## v3.7.1 の修正

「人生設計 → 行きたい場所」に、人生上の「分野」とは別の「場所の種類」を追加しました。観光・旅行、旅館・ホテル、温泉・入浴、飲食店・カフェ、買い物、医療機関、イベント・体験施設、その他から選べます。

旅館・ホテルを選ぶと、旅館、ホテル、温泉旅館、リゾートホテル、民宿・ペンション、キャンプ・グランピング、その他から宿泊施設の種類も選択できます。分類はカードとNotebookLMの `NLM_07_Wishes` にも表示します。以前の「旅行先・地域」「観光・景勝地」「宿泊」データは、観光・旅行／旅館・ホテルとして自動的に引き継ぎます。

## v3.7.0 の中心テーマ

Life Compassを、健康だけ・仕事だけに偏らず、過去・現在・未来を一つにつないで人生全体を前へ進める「AI人生相棒」へ強化しました。ホームには「守る・進める・楽しむ」の今日の3つと、8分野の人生バランスを表示します。

健康画面には公式医療情報ウォッチを追加しました。円錐角膜、角膜移植後のコンタクトレンズ、強膜レンズ、腰・脊柱管を初期テーマにし、PubMedの研究論文とClinicalTrials.govの臨床試験を区別して表示します。病名・身体部位・治療名は自由追加でき、脊柱管狭窄症の日帰り・低侵襲手術、椎間板再生、レーザー支援角膜移植、海外特殊レンズ、円錐角膜向け眼鏡、iPS角膜、培養角膜内皮細胞、自己細胞由来の角膜再生も選択候補にしています。

研究・臨床試験・日本での承認・保険適用は同じ意味ではないため、Minds、PMDA、厚生労働省、医療情報ネット（ナビイ）、再生医療提供機関、眼鏡作製技能士の確認先を役割別に示します。病院・クリニック・眼鏡店の候補はLife Compassへ保存し、製品名、国内承認、費用区分、実施経験、合併症、緊急時対応、再調整・返品、眼科連携を確認できます。診断や治療指示は行わず、相棒の状態に適するかは専門医へ確認する前提です。

エクスポートは、WEBRIC人生戦略ツール向けのプロフィール専用JSONと、NotebookLM向けの人生全体データを明確に分けました。KOTOKA・NEKKOは別ツールであり、本版では変更していません。

## v3.6.5 の修正

「連携・移行」へ、現在の名称であるWEBRIC人生戦略ツール専用のプロフィールJSON書き出しを追加しました。プロフィール画面へ入力した内容だけを書き出し、欲しいもの・行きたい場所・やりたいこと・目標・各記録・AI履歴は含めません。APIキー、GAS URL、同期トークン、スプレッドシートIDも含みません。

プロフィールの生年月日は、スマホのカレンダーを何十年も戻す方式から、「西暦年を直接入力＋月・日を選択」する方式へ変更しました。年は `1964` のように入力でき、月に応じて日数を自動調整します。保存時には現在の年齢も自動更新します。既存の生年月日は新しい入力欄へそのまま表示されます。

## v3.6.4 の修正

スマホの文字を従来版より大きく・太く・濃くし、本文、補足、入力欄、ボタン、下部メニューまで視認性を統一しました。設定には「最大」文字サイズも追加しています。

保存はIndexedDBへの再試行と読み返し確認を行い、大容量データを容量の小さいlocalStorageへ戻さないよう改善しました。端末保存が失敗しても同期設定済みならGoogle Sheets正本へ自動退避します。設定画面の「端末保存を診断」で端末側の保存状態も確認できます。

## v3.6.3 の修正

スマホ内に残る旧形式のAI履歴や部分更新データを保存時に自動補正し、ホーム画面および人生レーダー保存後に `Cannot read properties of undefined (reading 'length')` が出る問題を修正しました。v3.6.2の人型カルテ、鼻、口（歯）、人生ゲーム等はすべて維持しています。

## v3.6.2 の中心テーマ

### 1. 人型カルテ（身体マップ）

健康画面の最上部に前面・背面の身体図を配置しました。鼻と口（歯）を含む48部位の四角をタップし、痛み・治療・手術・経過観察を色分けして記録できます。病名・症状、病院、治療・手術内容、痛みの強さ、日付も同じ部位へ保存します。健康画面上部の「人型カルテを開く」からすぐ移動できます。

### 2. 理想の未来を人生ゲーム化

理想の未来画面に「現在地 → 次の一歩 → 中間クエスト → 叶えたいこと → 自分の勝利条件」のゲームボードを追加しました。最優先課題、目標、習慣、夢、理想の未来カードを自動で一本のルートにします。

### 3. 記録カードのグラフィック化

各記録にイメージアイコンと分類色を選べるようにしました。文章は詳しい情報として残しつつ、普段の一覧では絵・色・進捗を先に確認できます。

### 4. v3.5.0の機能をすべて継承

理想の未来、80歳の仮時間軸、最優先課題、カレンダー、NotebookLM、Universal AI Context Pack、PC・スマホ同期、IndexedDB容量対策を維持しています。

## v3.5.0 の中心テーマ

### 1. 「これから作る理想の人生」を独立ページ化

過去に思い描いた理想ではなく、今から作り上げたい人生を分野別カードとして記録できます。

- 健康
- 収入・お金
- 仕事・事業
- 家族
- 住宅・住環境
- ライフスタイル
- 人間関係
- 学び
- 趣味・楽しみ
- 生き方・価値観
- その他

各カードには、理想の状態、なぜ大切か、今とのギャップ、最初の一歩、目指す年齢、近づき具合、100%実現できなくても「近づいた」と感じる状態を記録できます。

**80歳は寿命予測ではありません。** 人生を楽しみながら理想へ近づくための仮の計画時間軸です。AIも「達成／未達」の合否ではなく、現在の選択が理想の方向へ近づいているかを評価します。

### 2. 理想イメージ画像をカードへ添付

ChatGPT等の画像生成AIで作った「理想の住まい・旅・暮らし・働き方」などの画像を複数添付できます。画像は既存のGoogle Drive添付機能で保存し、カード上でプレビューします。

カードには画像生成に使ったプロンプトやメモも保存できます。v3.5.0はLife Compass内部で画像を生成する機能ではなく、**外部で生成した画像を理想の未来カードへ蓄積する機能**です。

### 3. 理想と現実の「方向性」をAIが横断分析

AIコンテキストに「これから作る理想の人生」を追加しました。AIは以下を同時に見て、整合性やズレを分析できます。

- 理想の未来
- 目標
- 欲しいもの
- 行きたい場所
- やりたいこと
- 健康・医療
- 収入・支出・固定費・負債
- 最優先課題
- 家族
- 期限

理想の100%実現が難しい場合も、理想を捨てるのではなく、近づける部分、代替案、今できる一歩を提案するルールにしています。

### 4. Universal AI Context Pack

Life Compassを「メインの頭脳／正本」にして、ChatGPT、Gemini、Claude、その他のAIへ同じ背景を渡せる共通コンテキストを書き出せます。

- **Markdown**：通常のAIへのファイル添付に推奨
- **JSON**：構造化コンテキストを扱うAI・開発ツール向け
- **開始プロンプト**：新しいAIチャットの最初に貼る共通指示

外部へ渡すデータ範囲は項目ごとにON/OFFできます。APIキーと同期トークンは書き出しに含めません。

### 5. NotebookLM出力を拡張

NotebookLM用Google Sheetsに `NLM_11_Future_Life` を追加し、「これから作る理想の人生」を分析ソースに含めます。従来の正本シートは変更せず、NLMタブだけ再生成します。

## v3.8.0への更新手順

今回は**画面側だけの更新**です。Google Sheets正本・GAS・同期トークンは変更しません。

1. このZIPを解凍し、GitHub Pages側の公開ファイル一式を上書きします。
2. 公開後にブラウザを再読み込みします。
3. 古い表示が残る場合は、一度ページを閉じて開き直します。
4. `gas/Code.gs`、`appsscript.json`、スプレッドシート、`SPREADSHEET_ID`、`SYNC_TOKEN`、APIキーは変更不要です。

## 現在の主要機能

- ホーム：守る・進める・楽しむ、人生バランス、最優先課題、期限、人生スコア
- 最優先課題：今すぐ／すぐに／早めに／考えてから行動
- 人生設計：目標、習慣、欲しいもの、行きたい場所、やりたいこと、マインドマップ
- 理想の未来：80歳を仮の時間軸にした未来設計＋画像＋人生ゲームボード
- カレンダー：目標、最優先課題、医療、夢、返済などの期限を統合
- 健康：身体マップ＋プロフィール正本＋個別経過＋医療計画＋病院候補＋公式医療情報ウォッチ
- 事業：商品・顧客・課題・提供内容・検証
- お金：収入・支出・固定費・負債／借入
- 過去・現在・未来の人生タイムライン／定期レビュー
- AI人生相棒：Gemini／ChatGPT、人生全体・過去の強み・楽しみ・目標前進、忖度しない客観分析ルール
- AI連携：相棒専用GPT、外部AI向けコンテキスト
- Google Sheets同期、Google Drive添付、JSONバックアップ・移行
- NotebookLM用分析タブ生成
- PWA／スマホ・タブレット・PC対応

## データの役割

- **Google Sheets**：Life Compassのクラウド正本
- **Google Drive**：画像・添付ファイル
- **端末 IndexedDB**：高速表示とオフライン用キャッシュ
- **JSON**：バックアップ・移行
- **NLM_ タブ**：NotebookLMが読みやすい分析用ビュー
- **Universal AI Context Pack**：他のAIへ持ち運ぶための可搬コンテキスト

## 注意

健康、医療、家族、住所、収入、支出、負債などセンシティブな情報を含められます。外部AI用Context Packは必要な範囲だけ選択し、アップロード先サービスの共有・保存設定を確認してください。
